# Security Policy

## Supported versions

The most recent minor release of `validix` receives security fixes. Older versions are unsupported.

| Version  | Status     |
| -------- | ---------- |
| `0.1.x`  | Supported  |

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Instead, email **amkeitadugnaliben65@gmail.com** with:

- A description of the issue
- Steps (or a proof-of-concept) to reproduce it
- Any potential impact you've identified

You should expect an initial reply within **3 business days**. We aim to publish a fix and advisory within 30 days; longer if the issue is complex or requires a coordinated disclosure.

Thank you for helping keep `validix` users safe.
